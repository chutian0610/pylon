# Worker 无状态原则：中间状态外置

> 修订（2026-10）：shuffle 默认介质修正为 P2P 直连（Arrow Flight），外置存储降为
> 演进模式，见 ADR-0008。本 ADR 的无状态原则与"本地盘非事实来源"不变。

Worker 按无状态设计：shuffle 数据与可重建的执行状态不依赖本地盘持久，落在外部
介质上（对象存储 S3 类，或 Redis 类外部存储服务），本地盘只作可选缓存。这是存算
分离与弹性扩缩容的基础，也让 worker 丢失的恢复退化为"重新派发"。

边界：Pylon 不做 serverless。Worker 常驻并可弹性伸缩，不与单个查询的生命周期
绑定（明确否决"worker 生命周期 ≈ 查询生命周期"方向）。

## Consequences

- shuffle 默认走外部介质，需接受相应延迟并为之优化（异步预取、合并写）。
- 与 Trino 常驻 JVM 重状态集群形成差异化定位。
